# Security Policy

ToolsFam public repositories may contain examples, guides, checklists, and public roadmap items.

Please do not share sensitive information in issues, pull requests, comments, or example files.

## Do not post

- API keys
- Passwords
- JWT tokens
- Private documents
- Bank statements
- Customer data
- Personal identity documents
- Internal company data

## Reporting a security concern

If you find a security or privacy issue related to ToolsFam, please contact us through:

https://www.toolsfam.com/contact

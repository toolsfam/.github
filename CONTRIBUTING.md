# Contributing to ToolsFam Public Resources

Thanks for helping improve ToolsFam public resources.

These repositories are used for examples, guides, checklists, public roadmap items, and curated resources around privacy-first browser tools.

## What you can contribute

You can suggest:

- Useful browser-based tools
- Local-first workflow ideas
- JSON, CSV, API, SEO, PDF, and image examples
- Privacy checklist improvements
- Bug reports
- Tool requests
- Documentation fixes

## Contribution rules

Please keep contributions:

- Practical
- Clear
- Non-spammy
- Safe for public use
- Related to browser tools, developer workflows, file utilities, SEO, privacy, or productivity

## Do not submit

Please do not submit:

- Private user data
- Real API keys
- Real JWT tokens
- Personal documents
- Copyrighted files you do not own
- Spam links
- Low-quality AI-generated lists

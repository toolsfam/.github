# Code of Conduct

ToolsFam public repositories are intended to be useful, respectful, and beginner-friendly.

## Expected behavior

- Be respectful
- Be constructive
- Stay on topic
- Help improve the quality of public resources
- Avoid spam or self-promotion

## Unacceptable behavior

- Harassment
- Hate speech
- Spam
- Sharing private data
- Posting malicious links or files
- Submitting unsafe examples

## Reporting

If you see a problem, please contact ToolsFam through:

https://www.toolsfam.com/contact
